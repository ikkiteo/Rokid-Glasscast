# Виртуальный дисплей GlassCast

Кнопка **драйвер дисплея** в `GlassCast.exe` ставит отдельный монитор и расширяет на него рабочий стол. Сборка через Visual Studio не нужна.

Пакет лежит в `driver/usbmmidd`. Это подписанный Microsoft драйвер **USB Mobile Monitor** от Amyuni Technologies (https://www.amyuni.com). GlassCast его не писал; текст лицензии — `driver/usbmmidd/usbmmidd_v2/License.txt`.

После установки в списке источников выбери **виртуальный дисплей GlassCast**. Разрешение экрана — 1920×1080. Окна перетаскиваются на него как на обычный монитор.
